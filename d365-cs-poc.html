US-101 · ENTITLEMENT & SLA ROUTING

Priority Routing for Production-Down Cases

As a Customer Service Team Lead, I want incoming cases from Platinum accounts marked "Line Stoppage" to auto-route to the Priority Engineering Queue with a 15-minute SLA timer, so that critical customers never wait in general triage.

Acceptance Criteria (Given / When / Then):
Given an active Platinum Entitlement,
When a Case is created with Severity = Critical,
Then D365 assigns the Priority Queue within 30 seconds and starts the 15-min First-Response SLA clock.
US-102 · COPILOT KB DEFLECTION & HANDOFF

Grounded AI Self-Service with Human Escalation

As a B2B Support Customer, I want instant tooling specification answers from Copilot Studio with clear source citations and one-click specialist handoff, so that routine questions resolve immediately without dead-end bots.

Acceptance Criteria (Given / When / Then):
Given a portal inquiry matching a published KB article with ≥85% confidence,
When Copilot responds, it displays an AI disclosure notice + KB ID; if confidence <85%, it creates a D365 Case with full chat transcript attached.
US-103 · READ-ONLY ERP ORDER VISIBILITY

Zero-Custom-Code Order Status on Case Form

As a Support Specialist, I want to view live ERP shipment status directly inside the D365 Case side-panel, so that I do not switch across three legacy screens during customer calls.

Acceptance Criteria (Given / When / Then):
Given a valid ERP Order ID entered on the Case form,
When the agent opens the Order tab, Power Automate queries the ERP read-only API and displays dispatch ETA within 3 seconds without writing back to ERP.
